## MusicComposition/lyrics e Google: orientação técnica, sem implementação

Schema.org define lyrics em MusicComposition com valor CreativeWork; o texto pode ir em lyrics.text. Lyricist identifica quem escreveu as palavras. A gravação é MusicRecording, ligada à composição por recordingOf; composição e gravação não devem compartilhar o mesmo identificador por conveniência.

Exemplo documental usando somente o trecho permitido de Preço. Não colar no site antes de definir uma página real que mostre o mesmo texto:

```json
{
  "@context": "https://schema.org",
  "@type": "MusicComposition",
  "@id": "https://faguital.com.br/#composicao-preco",
  "name": "Preço",
  "lyricist": {
    "@type": "Person",
    "@id": "https://faguital.com.br/#person",
    "name": "Guilherme Carvalho de Andrade",
    "alternateName": "FAGUITAL"
  },
  "inLanguage": "pt-BR",
  "lyrics": {
    "@type": "CreativeWork",
    "name": "Trecho da letra de Preço",
    "inLanguage": "pt-BR",
    "text": "Eu não vou abandonar o sonho que me trouxe até aqui\nFoi fazendo tudo isso que eu finalmente me entendi\nMas talvez eu precise aprender, sem mudar quem eu sou\nA não deixar pra trás quem desde o começo me apoiou"
  }
}
```

Este exemplo identifica um trecho, não finge descrever letra completa. Nenhum HTML ou JSON-LD foi modificado nesta missão. Não adicionar composer sem confirmar autoria musical; nem ISRC/ISWC, lançamento, álbum ou contratos ausentes.

A galeria oficial de recursos da Pesquisa Google consultada não lista um rich result específico MusicComposition/lyrics. Schema válido não é garantia de letra no painel, indexação ou reconhecimento de entidade. Validar vocabulário no Schema Markup Validator; o Rich Results Test só cobre recursos suportados pelo Google.

Para missão de implementação separada: conferir indexabilidade, status HTTP, canonical e conteúdo textual visível no HTML de uma página por faixa. O acervo registra /musica/<id>/ como noindex e redirecionamento: não tratar essas URLs como páginas de letra já prontas para SEO. Não mudar noindex, sitemap, player ou geradores nesta missão.
